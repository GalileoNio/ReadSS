模块由三个 Go 源文件组成，是单一 `main` 包的入口层：
- `main.go`：声明 `--version`/`--data-dir`/`--subscribe`/`--probe`/`--test-comments`/`--fetch-comments`/`--recommend`/`--colors`/`--selftest` 等 CLI 标志，按优先级分支执行；若无 GUI 子命令，则打开 SQLite 数据库 (`reads.db`)、通过 `service.New` 组装业务服务、可选启动本地图片代理 (`internal/imgproxy`)，并用 `wails/v3/pkg/application` 嵌入前端 `frontend/dist` 资源与图标，启动 WebView2 窗口。
- `cli.go`：实现各无头子命令函数（`runSubscribe`、`runFetchComments`、`runTestComments` 等），复用 `store` + `service` 同一套路径进行脚本化订阅、评论抓取与页面分析，便于 CI 与手工验证。
- `selftest.go`：内嵌最小 RSS fixture（含恶意 HTML 片段）并校验 feed 解析、XSS 清理、评论缓存过期规则、存储幂等性、阅读状态保持及播客进度等关键行为，作为自测试套件。
依赖方向单向向外：本模块仅依赖 `reads/internal/{feed,model,service,store,imgproxy}` 与 `github.com/wailsapp/wails/v3`，不反向被 internal 包引用。
