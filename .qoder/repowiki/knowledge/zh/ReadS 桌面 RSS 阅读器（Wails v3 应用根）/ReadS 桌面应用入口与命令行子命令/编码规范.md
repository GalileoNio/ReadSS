- 每个无头子命令都遵循“解析参数 → 打开 store → service.New → ServiceStartup → 执行业务 → ServiceShutdown”的固定生命周期模式。
- 子命令的错误通过 `fmt.Fprintln(os.Stderr, ...)` 输出并以 `os.Exit(1)` 终止，成功路径打印可读摘要后返回 nil。
- 对持久化的断言使用带标签的 `fmt.Errorf("[store] ..." / "[feed] ..." / "[sanitize] ...")` 前缀，便于在 selftest 中快速定位失败域。
- CLI 标志统一通过 `flag.Bool/String/Int64` 定义并在 `flag.Parse()` 后按字符串非空或布尔值做早期分支 return，避免嵌套。
